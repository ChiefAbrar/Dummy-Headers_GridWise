# Third-party components

The solution uses system-provided open-source components rather than vendoring their source trees:

- Boost.Beast / Boost.Asio / Boost.JSON — Boost Software License.
- libcurl — curl project license.
- OpenSSL and related runtime dependencies are consumed through the system libcurl package where applicable.

The competition source code is original application code in this repository. Use the official project license texts supplied by the corresponding system packages for redistribution requirements.
